Countdown guide

Choose a mode

Standalone timer

Double-click display.html. Set minutes and seconds, then use Start, Pause, Resume, or Reset. On the server’s projection page, select Standalone timer to use the same controls.

Offline console

Double-click console.html to manage the timer and group queue on this computer. Keep the web folder intact. Use Open projection for a second window and keep the console open.

Online or LAN

Open the server address and pair the console to control the venue projection from another computer. Use Follow console on the projection page.

Run a session

  1. Start with an empty queue and N/A, or paste one group name per line. Select a group, then click Set as current to switch the timer to it.
  2. Use Batch edit to drag groups and check any you want to delete. Apply changes saves the draft as one update. Removing the current group during an active session requires confirmation.
  3. Set the duration, warning, finish sound, and volume. Use Test sound beside the sound selector to listen on your current computer. Select Save settings. The default sound plays three beeps that get louder, higher, and closer together, then holds a higher tone for about one second.
  4. Control the timer from the console. It stays at 00:00 when time is up. Select Next group, then Start.

Use Export queue and settings and Import backup to transfer data between the public, LAN, and browser modes.

Set up the projection

  1. On Windows, press Win + P and choose Extend.
  2. Open the regular projection on the venue computer. It plays the selected finish sound by default. Choose Mute or set volume to 0 for silent timing.
  3. Move the projection window to the second display. Set Light theme or Dark theme, then choose Fullscreen. Press Esc to restore the controls.

If the browser requires a click before playing audio, clicking Fullscreen also enables it. If needed, use Enable sound on the projection. Use Preview on projection from the console to check the venue speakers.

The final 10 seconds start with 5 seconds of gentle contrast changes, build for 3 seconds, then flash between light and dark for 2 seconds. With reduced motion enabled, the display keeps a steady theme.

Use the Windows LAN backup

On the venue computer, double-click start.bat and enter L. With Python 3.10+ installed, it opens the local console and prints the LAN address and pairing code for the teacher.

Allow inbound TCP port 8765 on the trusted Windows network. From the teacher’s computer, test the venue address in PowerShell.

Test-NetConnection 192.168.1.20 -Port 8765

Replace the sample IP with the venue computer’s address. If the address and firewall are correct and the test fails, use a permitted hotspot or the venue console.

Display the current time

Open Clock or double-click clock.html. The main clock starts in the computer’s time zone. Change the main clock size, choose a main time zone if needed, and check other cities to show them below in smaller type.

Choose Device time, Network time, or Both. Network time comes from the countdown server’s system clock. The hosted page uses its own server. In the local HTML file, enter the console’s HTTP or HTTPS address, including a subpath such as /timer/ when applicable, then click Sync now. Device time works offline.

Presentation and Q&A

In the console, enable Two stages per group, set the Presentation and Q&A times, and save. Use Open projection to show the current group, stage, and queue. This works from the paired online or LAN console and from the local offline console.

Turn on Automatically start Q&A for continuous timing. With it off, Presentation holds at 00:00 until you select Start Q&A on the console. After Q&A, Next group prepares that group’s Presentation. Reset returns to the current group’s Presentation. Changes to stage timing made mid-group apply on reset or the next group.

For a single local timer, double-click two-stage.html or select Standalone timer in the two-stage projection. Its controls appear on the right on wide screens. Press Esc to reveal them from fullscreen.

Resume or clear temporary state

This browser can restore recent local countdowns, queue drafts, and mode choices for about 30 minutes. A running local countdown keeps its original deadline. If it expired while closed, it opens at 00:00 without replaying the sound. Online projection always syncs to the server. After reopening a paired console, enter the current pairing code again if the browser did not restore the tab session.

Use Clear temporary state to discard these records and reset local timer progress. Saved queues, settings, and the server countdown stay in place. Browsers can store local HTML files separately, so use the button on each local page whose state you want to clear.

--public-url tells Python which browser origin to accept for pairing and control. Nginx handles the HTTPS connection and can forward to Python over HTTP. Use the scheme, host, and any non-default port, for example https://example.edu for a page at https://example.edu/timer/.

--lan starts a local-network HTTP service, listens on all IPv4 interfaces by default, and saves to data/lan.json. It skips the public URL setting.

COUNTDOWN_PUBLIC_URL is optional. Set it on the server if you prefer to configure the same origin through an environment variable. Set it on a Windows client if you want start.bat to skip its prompt and open the full console URL, including /timer/ if applicable. If you type the address or specify --public-url where needed, you can leave the variable unset.

The following Linux examples use /opt/countdown. Copy server.py, timer_state.py, and the complete web/ folder there. Use Python 3.10+ and a service account that can write to /opt/countdown/data. Both methods use the same data file and port. Stop one instance before switching methods.

# Run from the project folder on the server
sudo install -d /opt/countdown
sudo cp -R server.py timer_state.py web /opt/countdown/
sudo install -d -o "$(id -un)" /opt/countdown/data
python3 --version

A. Direct HTTP

Start the server on all IPv4 interfaces. In the OS firewall and hosting firewall, allow TCP 8765 from your participants’ IP addresses or private network.

The command below uses env -u to unset any inherited COUNTDOWN_PUBLIC_URL for this Python process. It leaves the current shell’s environment intact.

cd /opt/countdown
env -u COUNTDOWN_PUBLIC_URL python3 server.py --host 0.0.0.0 --port 8765

Open http://SERVER_IP:8765/ directly in a browser. The projection is at http://SERVER_IP:8765/display. HTTP sends the pairing code and control traffic in clear text, so use this option on a trusted network or over a VPN.

B. HTTPS with Nginx

  1. Point your domain’s DNS to the server. Allow inbound TCP 80 and 443 for Nginx. Python will listen on loopback, so keep 8765 closed externally.
  2. Use an existing certificate for the domain, or install Certbot with its Nginx plugin. To obtain a certificate, first enable this temporary HTTP site in Nginx and reload it.
server {
    listen 80;
    server_name timer.example.edu;
    location / { return 200 "Countdown certificate setup\n"; }
}

On Debian or Ubuntu, save this site as /etc/nginx/sites-available/countdown and create the symlink once. If it is already enabled, start with the second command.

sudo ln -s /etc/nginx/sites-available/countdown /etc/nginx/sites-enabled/countdown
sudo nginx -t && sudo systemctl reload nginx
sudo certbot certonly --nginx -d timer.example.edu

Start Python on the same host, with the exact HTTPS origin your browsers will use.

cd /opt/countdown
python3 server.py --host 127.0.0.1 --port 8765 --public-url https://timer.example.edu

You can supply the address through the environment instead. If both are set, Python uses the explicit --public-url argument.

COUNTDOWN_PUBLIC_URL=https://timer.example.edu python3 server.py --host 127.0.0.1 --port 8765

On Windows, start.bat reads the same optional variable to open the public console without prompting. The following example sets it for the current Command Prompt. Use start.bat lan to choose the LAN backup.

set "COUNTDOWN_PUBLIC_URL=https://timer.example.edu"
start.bat

Replace the temporary site with the following Nginx configuration. On Debian or Ubuntu, for example, save it in /etc/nginx/sites-available/countdown and enable it with a symlink in sites-enabled/. Substitute your domain and actual certificate paths.

server {
    listen 80;
    server_name timer.example.edu;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name timer.example.edu;
    ssl_certificate /etc/letsencrypt/live/timer.example.edu/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/timer.example.edu/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_set_header Host $host;
        proxy_buffering off;
        proxy_cache off;
        gzip off;
        proxy_read_timeout 30s;
        client_max_body_size 384k;
    }
}
sudo nginx -t && sudo systemctl reload nginx
curl -N https://timer.example.edu/api/events

The last command should print a welcome event, then heartbeats. Press Ctrl + C to stop it. In a browser, open https://timer.example.edu/ and pair with the code printed by Python. Keep Python running. By default, the code changes on each restart.

Add a timer to an existing site at /timer/

If Nginx already serves https://example.edu, run Python with the site origin below and add these two locations inside the existing server block that serves HTTPS. Keep the domain and certificate already configured for the site.

python3 server.py --public-url https://example.edu
location = /timer {
    return 308 /timer/$is_args$args;
}

location ^~ /timer/ {
    proxy_pass http://127.0.0.1:8765/;
    proxy_set_header Host $host;
    proxy_buffering off;
    proxy_cache off;
    gzip off;
    proxy_read_timeout 30s;
    client_max_body_size 384k;
}

Keep the trailing slash in proxy_pass so Nginx strips /timer/ before forwarding. Run sudo nginx -t && sudo systemctl reload nginx. Visiting https://example.edu/timer redirects to /timer/. Use that full address in the browser or Windows launcher. Python’s --public-url takes only the origin. Nginx path forwarding

Choose a pairing code

python3 server.py --public-url https://example.edu --pairing-code RoomTimer2026
python server.py --lan --open --pairing-code RoomTimer2026

Replace the example with 6–32 letters or digits. Pairing is case-insensitive. Run with the same argument on each start to keep that code, or omit it to generate a fresh random code. Controllers pair again after a restart.

Automatic shutdown

Run the command on the machine hosting Python. Use --run-for with a positive number of seconds (90 or 90s), or combine hours, minutes, and seconds in order (2h30m or 1m15s).

python3 server.py --public-url https://timer.example.edu --run-for 2h30m
python server.py --lan --open --run-for 45m
python server.py --help

The clock starts when the server is ready and counts idle time. At expiry the server closes its connections and exits with status 0, even if a countdown is running. Saved queues and settings are kept. On restart, the timer is ready to start. Omit the option to keep the server running until stopped manually. If you use a process manager, configure it to leave a successful exit stopped.

选择使用方式

独立计时

双击 display.html，输入分钟和秒，点设置时长，即可开始、暂停、继续或重置。服务器的投影页也可点独立计时使用这套控件。

离线控制台

双击 console.html，可在本机管理倒计时和小组队列。请保留完整的 web 文件夹。点打开投影页可另开窗口，投影时保持控制台打开。

在线或局域网

打开服务地址并配对控制台，即可在另一台电脑操作现场投影。投影页使用跟随控制台。

组织演示

  1. 空队列也能开始计时，当前显示 N/A。需要小组时，每行粘贴一个组名。选中组名后点设为当前才会切组。
  2. 点批量编辑可拖动排序、勾选待删除的小组。点应用更改后统一生效。计时进行中删除当前组需要确认。
  3. 设置默认时长、预警、铃声和音量，点保存设置。选择铃声旁的试听会在当前电脑播放。默认铃声是三声短滴，间隔逐次缩短，音调和响度逐次升高，最后接一声约 1 秒的高音长滴。
  4. 从控制台操作计时。归零会停在 00:00。点下一组后，再点开始。

在公共服务、局域网和浏览器离线模式之间，可用导出队列和设置与导入备份转移数据。

准备投影

  1. Windows 上按 Win + P，选择扩展。
  2. 在现场电脑直接打开普通投影页。默认会播放设定的到时铃声。需要安静计时时，选择静音或把音量设为 0。
  3. 把投影窗口移到第二块屏幕。选浅色主题或深色主题，再点全屏。按 Esc 恢复控件。

如果浏览器要求先点击页面，点全屏时也会启用声音。需要时也可以点投影页的启用声音。可在控制台点在投影端试听检查现场音响。

最后 10 秒先轻缓变化 5 秒，再加强 3 秒，最后 2 秒交替明暗。系统开启减少动态效果时，画面保持同一主题。

使用 Windows 局域网备用

现场电脑安装 Python 3.10+ 后，双击 start.bat 并输入 L。脚本会打开本机控制台，并显示教师使用的局域网地址和配对码。

在可信的 Windows 网络配置文件上允许入站 TCP 8765。教师电脑可用 PowerShell 测试连通性。

Test-NetConnection 192.168.1.20 -Port 8765

将示例 IP 换成现场机的地址。若地址和防火墙均正确但仍连不通，可使用允许互通的热点，或改用现场控制台。

显示当前时间

打开时钟或双击 clock.html。主钟默认使用电脑当前时区，可调整主钟字号、改选主时区，并勾选要在下方用较小字号显示的城市。

可选择本机时间、网络时间或同时显示。网络时间取自倒计时服务器的系统时钟。服务器上的页面自动向同一服务同步。直接打开本地 HTML 时，填入控制台的 HTTP 或 HTTPS 地址（如有 /timer/ 等子路径，一并填写），再点立即同步。本机时间可离线使用。

Presentation 与 Q&A 双阶段计时

在控制台勾选每组两阶段，分别设置 Presentation 和 Q&A 时长，点保存后打开投影页。投影显示当前组、阶段和待场队列。在线、局域网和本机离线控制台都支持。

勾选自动开始 Q&A可连续计时。关闭时，Presentation 停在 00:00，在控制台点开始 Q&A继续。问答归零后，点下一组准备下一组的 Presentation。重置会回到当前组的 Presentation。计时中修改的阶段时长在重置或切组后生效。

单页使用时，双击 two-stage.html 或在双阶段投影页点独立计时。宽屏的操作控件在右侧。全屏时按 Esc 恢复控件。

恢复或清除临时状态

浏览器可在约 30 分钟内恢复本机计时、队列草稿和模式选择。正在运行的本机计时保留原截止时间。关闭期间归零的页面会显示 00:00，不会补播铃声。在线投影以服务器为准。重新打开控制台时，如果浏览器没有恢复原标签页会话，请重新配对。

点清除临时状态可删除这些记录并重置本机计时进度。已保存的队列、设置和服务端正在进行的计时会保留。浏览器可能为不同的本地 HTML 文件单独保存状态，可分别打开对应页面清除。

A. 不使用 HTTPS，直接通过 HTTP 访问

让 Python 监听所有 IPv4 接口。在服务器防火墙和云平台安全组中，允许参与者的 IP 或私有网络访问入站 TCP 8765。

下面的 env -u 只在这次启动 Python 时取消继承来的 COUNTDOWN_PUBLIC_URL。当前终端里的变量会保留。

cd /opt/countdown
env -u COUNTDOWN_PUBLIC_URL python3 server.py --host 0.0.0.0 --port 8765

在浏览器直接访问 http://服务器IP:8765/，投影地址是 http://服务器IP:8765/display。HTTP 会明文传输配对码和控制请求，适用于可信网络或 VPN 内的临时部署。

B. 使用 Nginx 配置 HTTPS

  1. 将域名 DNS 指向服务器，放行 Nginx 的入站 TCP 80 和 443。Python 只监听本机，外部无需开放 8765。
  2. 准备该域名的证书。已有证书可直接配置。若要用 Certbot 申请，先安装 Certbot 和 Nginx 插件，启用下面的临时 HTTP 站点并重新加载 Nginx。
server {
    listen 80;
    server_name timer.example.edu;
    location / { return 200 "Countdown certificate setup\n"; }
}

在 Debian 或 Ubuntu，将上述内容保存到 /etc/nginx/sites-available/countdown，并创建符号链接。站点已启用时，从第二条命令开始。

sudo ln -s /etc/nginx/sites-available/countdown /etc/nginx/sites-enabled/countdown
sudo nginx -t && sudo systemctl reload nginx
sudo certbot certonly --nginx -d timer.example.edu

在同一台机器上启动 Python。--public-url 填浏览器实际使用的 HTTPS 地址。

cd /opt/countdown
python3 server.py --host 127.0.0.1 --port 8765 --public-url https://timer.example.edu

也可以用环境变量提供同一个地址。两种写法同时使用时，Python 以命令行的 --public-url 为准。

COUNTDOWN_PUBLIC_URL=https://timer.example.edu python3 server.py --host 127.0.0.1 --port 8765

Windows 上的 start.bat 也读取这个可选变量，有值时会直接打开公共控制台。下面的设置仅对当前命令提示符窗口生效。要启动局域网备用，可运行 start.bat lan。

set "COUNTDOWN_PUBLIC_URL=https://timer.example.edu"
start.bat

在已有网站下挂载 /timer/

手动指定配对码

python3 server.py --public-url https://example.edu --pairing-code RoomTimer2026
python server.py --lan --open --pairing-code RoomTimer2026

将示例换成 6–32 位英文字母或数字，配对时不区分大小写。每次启动传入同一个值即可沿用；省略参数时会随机生成。服务重启后控制台仍需重新配对。

限时运行并自动退出

在运行 Python 的机器上加 --run-for。可以用正整数秒（90 或 90s），也可以按小时、分钟、秒顺序组合（2h30m 或 1m15s）。

python3 server.py --public-url https://timer.example.edu --run-for 2h30m
python server.py --lan --open --run-for 45m
python server.py --help

从服务就绪时开始计时，空闲时间也计入。到期后服务关闭连接，以状态码 0 退出，即使某组还在计时。已保存的队列和设置会保留，再启动时计时器处于待开始状态。省略参数时由你手动停止。若使用进程管理器，请避免让它在正常退出后立即重启服务。
